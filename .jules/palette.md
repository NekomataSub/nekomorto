## 2026-05-30 - Added ARIA labels to dashboard translations tab
**Learning:** Icon-only buttons (like `DashboardActionButton` containing only an icon like `<Trash2 />`) inside map loops (like dynamic lists or tables) must include specific dynamic content in their `aria-label`s (e.g., `aria-label={\`Remover tradução do gênero ${genre}\`}`). This allows screen reader users to distinguish between individual items, rather than hearing repeated, identical static labels. The internal icon should have `aria-hidden="true"`.
**Action:** When adding or fixing accessibility for icon-only buttons inside list loops, ensure the `aria-label` leverages the list item's unique identifier (e.g., name, ID) to create a distinct and descriptive label. Ensure to translate ARIA labels into Portuguese, matching the primary UI language.
