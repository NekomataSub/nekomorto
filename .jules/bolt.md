## 2024-05-18 - String Sorting Optimization
**Learning:** `String.prototype.localeCompare` creates a significant bottleneck when sorting arrays in JavaScript because it initializes the locale settings on every comparison within the `sort()` loop. In an application where complex objects are sorted by string properties, this causes a severe O(N log N) performance hit.
**Action:** Always prefer initializing `new Intl.Collator` once outside the sorting logic and using its `.compare` method. For exact parity with default `localeCompare` behavior (respecting case and accents), use `{ sensitivity: "variant" }`.
